· 两张图片支持 拖拽、选择文件、手动输入本地路径 三种方式确定路径。
· 提取结果默认保存在缓存目录，7 天后自动删除；点击「保存到 out 目录」后永久保存到 out 目录。
· 容差为 0 时，任何一个像素通道存在差异即被提取；调大容差可忽略轻微噪点。
· 预览操作：滚轮以光标为中心缩放，拖动平移，双击或点「100%」复位，「适应窗口」一键铺满。
· 算法（默认）：差异像素取取色来源的原始颜色、alpha=255；来源像素自身是半透明（alpha 在 1-254）时保留其原始 alpha；来源像素 alpha=0 时输出 alpha=0。把结果按 alpha 叠加到底图上逐像素精确等于提取图片（误差为 0），因此不可能产生杂色。
· 边缘羽化：默认 1px。在差异掩码的边界外侧生成 alpha 渐变（颜色按精确解族反解），因此素材放到新背景上时边缘自然过渡、不再出现硬边锯齿；同时叠回原底图仍逐像素精确还原目标图。设为 0 则完全硬边。注意：羽化的数学前提是「掩码外侧像素在两图中的颜色一致」，故它只改变边缘过渡，不会在内容区产生杂色。
· 半透明像素：alpha 在 1-254 之间的像素判定为半透明，提取后保留其原始透明度；两图都全透明（alpha=0）的像素视为相同，其 RGB 不参与比较。
· 半透明归因（旧版算法，可选，默认关闭）：开启后回到最初的 un-blending 路径——直接输出带 alpha 值的透明 PNG（正是最早那版的效果），求解每像素 (alpha, 真实色) 使提取物叠加底图后还原来源图。代价是该解法对不透明源图（如普通截图）会强行反解出“极小 alpha + 极端颜色”，边缘出现彩色杂色。开启后出现「透明判定」滑块（默认 100% = 完全归因半透明），且需重新点一次「开始提取」方才生效；开启时的“杂色抑制”仅对该路径生效。
· 四角定位像素：默认在生成图片四角绘制纯红实心标记，便于在 Photoshop 中定位画布（选中标记即知边界）；不需要时取消勾选即可。
